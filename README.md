Developed the frontend of FoodShare, a responsive web application aimed at reducing food waste by connecting individuals and businesses with surplus food to community members in need. The platform facilitates easy sharing and discovery of excess food items, promoting sustainability and community engagement.

Key Features:

User-friendly interface for posting and browsing available surplus food.

Search and filter functionality based on food type, distance, and dietary preferences.

Direct messaging system to coordinate pickups between donors and recipients.

Responsive design ensuring accessibility across various devices.

 Next.js and Tailwind CSS
